# Hierarquia Visual e Composição de Layout

## Princípio central
Em até 3 segundos o visitante deve entender: (1) o que é este negócio/produto, (2) por que confiar nele, (3) o que deve clicar. Todo layout deve ser desenhado de trás para frente a partir dessa regra.

## Técnicas
- **Tamanho e peso**: o elemento mais importante da tela deve ser visivelmente o maior/mais pesado — nunca dois elementos competindo pelo mesmo peso visual.
- **Contraste de cor**: reserve a cor de destaque (accent) exclusivamente para a ação principal (CTA). Se tudo é colorido, nada se destaca.
- **Zona F / Z**: em textos e listas, organize conteúdo denso seguindo o padrão de leitura em F; em landing pages, alterne layout em Z (imagem-texto, texto-imagem) a cada seção para manter ritmo visual.
- **Espaço negativo**: use espaço em branco para agrupar (proximidade) elementos relacionados e separar os não relacionados — nunca distribua tudo uniformemente.
- **Alinhamento**: tudo deve alinhar a uma grade invisível; elementos desalinhados por "achismo" quebram a percepção de qualidade instantaneamente.
- **Um CTA primário por tela/seção**: múltiplos botões do mesmo peso visual confundem o usuário e reduzem conversão.

## Ordem de leitura em páginas de conversão
1. Hero (promessa + prova + CTA)
2. Prova/autoridade rápida (logos, números, selos)
3. Problema → solução (o que o visitante sente vs. o que você resolve)
4. Como funciona / serviços (com visual, não só texto)
5. Prova social aprofundada (depoimentos, cases, antes/depois)
6. Diferenciais concretos
7. Objeções/FAQ
8. CTA final + contato/localização

## Checklist
- [ ] Existe UM elemento dominante por seção?
- [ ] O CTA principal é visualmente único (cor exclusiva)?
- [ ] O espaço em branco agrupa/separa corretamente a informação?
- [ ] A ordem das seções segue a lógica de decisão do visitante, não uma lista aleatória?
