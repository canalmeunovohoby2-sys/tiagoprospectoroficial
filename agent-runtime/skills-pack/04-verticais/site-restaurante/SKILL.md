# Site para Restaurante e Delivery

## Identidade visual esperada
- Paleta e tom devem refletir o tipo de cozinha/experiência (ex: tons terrosos e quentes para culinária rústica/italiana, preto/dourado para alta gastronomia, cores vibrantes para casual/delivery jovem).
- Fotografia de prato profissional é decisiva — nunca usar imagens de banco genéricas de comida "internacional" sem relação com o cardápio real.

## Seções obrigatórias
1. Hero com imagem/vídeo de ambiente ou prato-assinatura + CTA "Ver cardápio" / "Reservar mesa" / "Pedir agora".
2. Cardápio digital navegável por categoria, com fotos, descrição apetitosa (não só lista de ingredientes) e preço.
3. Ambiente (fotos do espaço) para quem busca experiência presencial.
4. Reservas: formulário/integração com sistema de reservas ou WhatsApp direto.
5. Delivery: link direto para os apps parceiros (iFood, Rappi) e/ou pedido próprio via WhatsApp/carrinho.
6. Avaliações (Google, Tripadvisor) e depoimentos.
7. Localização com mapa, horário de funcionamento, estacionamento.
8. Eventos/promoções especiais quando houver (happy hour, menu executivo).

## Diferenciais de conversão
- Fotografia apetitosa é o maior fator de conversão do segmento — priorizar sempre.
- Facilidade de pedido/reserva em poucos cliques é mais importante que texto longo institucional.
