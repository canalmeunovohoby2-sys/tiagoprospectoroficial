# Site para Arquitetura e Design de Interiores

## Identidade visual esperada
- Extremo minimalismo: muito espaço em branco, tipografia refinada (frequentemente serifada elegante ou sans-serif geométrica fina), paleta quase monocromática (preto/branco/bege) deixando o portfólio fotográfico ser o protagonista absoluto.
- Fotografia de projetos em altíssima resolução, com composição cuidadosa — este segmento tolera zero fotografia de banco de imagens genérica.

## Seções obrigatórias
1. Hero minimalista: uma imagem de projeto de forte impacto + nome do escritório + uma frase de posicionamento, sem excesso de texto.
2. Portfólio/projetos em grid editorial, cada projeto com página própria (galeria, conceito do projeto, metragem, localização).
3. Sobre o escritório: filosofia de trabalho, formação dos arquitetos (CAU), prêmios/publicações se houver.
4. Serviços: projeto arquitetônico, interiores, paisagismo, consultoria — com escopo claro de cada etapa.
5. Processo de trabalho (briefing → conceito → projeto executivo → acompanhamento de obra).
6. Depoimentos de clientes (discretos, elegantes, sem exagero promocional).
7. Contato com formulário qualificador (tipo de projeto, metragem, orçamento estimado).

## Diferenciais de conversão
- Este segmento vende percepção estética diretamente através do próprio site — o site em si é prova de competência; qualquer elemento genérico quebra a credibilidade imediatamente.
