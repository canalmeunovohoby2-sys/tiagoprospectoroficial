# FAQ como Quebra de Objeções

## Abordagem
Um FAQ bem feito não responde perguntas genéricas — ele antecipa e neutraliza as objeções reais que impedem a conversão. Pergunte-se: "o que faz esse visitante hesitar em fechar?"

## Categorias de objeção a cobrir por segmento
- **Preço/investimento**: "Quanto custa?", "Tem parcelamento?", "Vale a pena comparado a X?"
- **Confiança/segurança**: "É seguro?", "Vocês são licenciados/regulamentados?", "O que acontece se eu não gostar do resultado?"
- **Tempo/conveniência**: "Quanto tempo demora?", "Preciso ir pessoalmente?"
- **Garantia/risco**: "Tem garantia?", "Posso cancelar?", "O que está incluso?"
- **Comparação**: "Qual a diferença para [alternativa]?"

## Formato
- Perguntas na linguagem real do cliente (como ele perguntaria, não como um advogado escreveria).
- Respostas curtas, diretas, terminando quando possível com um reforço de confiança ou um CTA leve.
- Marcar com Schema `FAQPage` (JSON-LD) para ganhar rich snippet no Google — ver skill `seo-technical-onpage`.
- Accordion/colapsável para não poluir a página, com animação suave (ver `microinteractions-animations`).

## Checklist
- [ ] As perguntas refletem objeções reais de venda, não só dúvidas operacionais triviais?
- [ ] Preço, garantia e segurança foram endereçados quando relevantes ao segmento?
- [ ] Schema FAQPage foi incluído?
