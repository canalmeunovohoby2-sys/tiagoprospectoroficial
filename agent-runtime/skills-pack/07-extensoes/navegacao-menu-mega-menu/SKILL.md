# Navegação e Mega Menu

## Arquitetura de informação antes do visual
- Mapear todas as páginas do site em uma árvore hierárquica antes de desenhar o menu — nunca adicionar itens de menu de forma improvisada conforme páginas vão sendo criadas.
- Máximo de 5-7 itens no menu principal; se houver mais categorias, agrupar em mega menu com subcategorias, não uma linha horizontal infinita.

## Mega menu (quando o site tem catálogo/muitas categorias)
- Organizar por categoria com subcategorias visíveis de uma vez (não dropdown simples empilhado), idealmente com um destaque visual (imagem, produto em destaque, link "ver tudo").
- Em mobile, mega menu vira menu de navegação em camadas (drill-down) dentro do drawer/hambúrguer — nunca tentar replicar o mega menu horizontal em tela pequena.

## Breadcrumbs
- Em sites com hierarquia profunda (e-commerce, blog, imóveis), sempre incluir breadcrumb (Home > Categoria > Subcategoria > Item) — ajuda navegação e SEO (Schema BreadcrumbList).

## Rodapé como navegação secundária
- Rodapé deve conter links importantes que não cabem no menu principal (políticas, todas as categorias, redes sociais, links institucionais) — é frequentemente subestimado, mas é onde o usuário procura quando não encontra algo no topo.

## Checklist
- [ ] O menu principal tem no máximo 5-7 itens visíveis, com agrupamento para o resto?
- [ ] Existe breadcrumb em páginas de hierarquia profunda?
- [ ] O rodapé cobre os links que não cabem na navegação principal?
