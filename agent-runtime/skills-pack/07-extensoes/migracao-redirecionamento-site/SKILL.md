# Migração e Redirecionamento de Site

## Por que é crítico
Trocar de site sem planejamento de migração é a causa mais comum de um negócio "sumir do Google" da noite para o dia, mesmo com um site novo mais bonito — o SEO acumulado se perde se as URLs antigas não forem tratadas.

## Processo obrigatório antes de lançar o site novo
1. Mapear TODAS as URLs indexadas do site antigo (via Google Search Console, sitemap antigo, ou rastreador de site).
2. Criar redirecionamento 301 (permanente) de cada URL antiga para a URL nova correspondente mais próxima em conteúdo — nunca redirecionar tudo genericamente para a home (isso derruba o SEO tanto quanto não redirecionar).
3. Preservar, na nova versão, os elementos de SEO que já funcionavam (títulos, estrutura de conteúdo que já ranqueava bem), a menos que haja razão forte para mudar.
4. Atualizar o sitemap.xml e reenviar ao Google Search Console assim que o site novo for ao ar.
5. Monitorar por 2-4 semanas após o lançamento: tráfego orgânico, erros 404 no Search Console, posições de palavras-chave principais — agir rápido se algo cair fora do esperado.

## Checklist
- [ ] Todas as URLs antigas relevantes têm redirecionamento 301 mapeado individualmente?
- [ ] O sitemap novo foi enviado ao Google Search Console após o lançamento?
- [ ] Há monitoramento de tráfego/erros nas semanas seguintes ao lançamento?
